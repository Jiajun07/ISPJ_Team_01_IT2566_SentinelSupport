How USB MFA Works
  1. Generate Key: Click "Generate MFA Key" to create a unique key file
  2. Download File: Download the mfa_key.json file
  3. Save to USB: Copy the file to the root of your USB thumbdrive
  4. Enable MFA: Click "Enable USB MFA" to activate
  5. Login: Insert USB during login - authentication will be automatic!
⚠️ Important: Keep your USB drive safe! If lost, you can regenerate a key, but your old one will be invalidated.
